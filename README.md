# 🛒 МойМаркет — Прототип интернет-магазина (SPA)

Интерактивное веб-приложение, разработанное как pet-проект для портфолио. Представляет собой клиентскую часть современного маркетплейса с полным циклом покупки: от поиска товара до оформления заказа.

## 🔗 Живое демо
👉 [Посмотреть работающий сайт](http://localhost:5173/)

## 🚀 Функционал
* **Каталог товаров:** Адаптивная сетка товаров (от 1 до 4 колонок в зависимости от размера экрана).
* **Поиск:** Мгновенная фильтрация товаров по названию и категории.
* **Фильтрация:** Рабочие кнопки категорий с визуальным выделением активного состояния.
* **Карусель (Слайдер):** Автоматическая прокрутка баннеров с возможностью ручного переключения и индикаторами.
* **Корзина:** 
  * Добавление и удаление товаров.
  * Подсчет общей суммы и количества.
  * Сохранение состояния в `localStorage` (данные не теряются при перезагрузке страницы).
* **Авторизация (Имитация):** Модальное окно входа с сохранением имени пользователя в `localStorage`.
* **Адаптивность:** Полностью адаптивный дизайн (Mobile First) с использованием Tailwind CSS.

## 🛠️ Стек технологий
* **React** (Функциональные компоненты, хуки)
* **TypeScript** (Строгая типизация данных и пропсов)
* **Vite** (Сборщик проекта)
* **React Router DOM** (Маршрутизация)
* **Context API** (Глобальное состояние для корзины и авторизации)
* **Tailwind CSS** (Стилизация и адаптивность)
* **Lucide React** (Иконки)

## 📦 Установка и запуск
Для запуска проекта локально выполните следующие команды:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/твой-ник/my-marketplace.git

2. Перейдите в папку проекта:
```bash
cd my-marketplace

3. Установите зависимости:
```bash
npm install

4. Запустите сервер для разработки:
```bash
npm run dev

5. Откройте http://localhost:5173 в браузере.
